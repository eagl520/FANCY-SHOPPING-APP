 Fancy 🛍️

A modern e-commerce shopping mobile application built with Flutter, Dart, and Firebase.

 📱 About the Project

Fancy helps users browse, manage, and purchase their favorite products in one simple application.

The app provides a clean dashboard where users can view products, add items to their shopping cart, manage quantities, and complete secure checkouts.

 ✨ Features

* 🛒 User Registration & Login
* 🔒 Secure User Authentication with Firebase
* 🛍️ Browse Products by Categories
* 🔍 Search & Filter Items
* ➕ Add to Cart & Manage Quantities
* 💳 Smooth Checkout Process
* 📦 Order History Tracking
* ☁️ Cloud Firestore Database
* 👤 User-specific data security
* 📱 Responsive Flutter interface
* 🎨 Modern Material 3 UI

 🛠️ Technologies Used

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore
* Material 3
* Git & GitHub

 ⚙️ How It Works

1. User creates an account or logs in.
2. Firebase Authentication securely manages the user account.
3. The user browses products from the main dashboard.
4. Products and cart details are stored in Cloud Firestore.
5. Each user's data is protected using Firebase Security Rules.
6. Users can complete orders and track their purchases seamlessly.

 🔒 Firebase Security

Fancy uses Firebase Authentication and Firestore Security Rules to ensure that users can only access their own cart and order details.
